Important 1: Formulating a supervised learning task

The aim of this exercise is to practise formulating a well-defined supervised learning task in the sense of Definition 1.1. That is, for each of the following real-world tasks, identify suitable choices of \mathcal{X}, \mathcal{Y}, \mathcal{Z} and L, and suggest suitable training data, in order to turn the real-world task into a supervised learning task.

  1. An unknown food ingredient can make me feel unwell, and I would like to find out what it is.

  2. I accidentally had my thumb in the way when taking a photo, so part of the image is obscured. I would like to digitally remove my thumb and fill the region that was obscured with realistic content.

Formulating a well-defined task is often the main challenge in real-world applications of machine learning, together with acquiring a suitable training dataset.

Solution

There is no unique solution here; the main goal is to think about what is required to define a well-posed supervised learning task.

An example solution for the first problem is:

  • \mathcal{X} = \{0,1\}^d, where \mathbf{x}_i is a binary vector indicating the presence or absence of d different common allergens in the ith item of food that was consumed.

  • \mathcal{Y} = \{0,1\}, where y_i indicates whether or not symptoms occurred after eating the ith item of food.

  • \mathcal{Z} = \mathcal{P}(\{0,1\}), so that the output f(\mathbf{x}) of a machine learning model is a probabilistic prediction for whether symptoms occur after consuming food with allergen profile \mathbf{x}.

  • L(y,P) = -\log p(y), the cross-entropy loss associated with the predictive distribution P (with probability mass function p) when the observed response is y (recall how this loss function is used for classification tasks in Example 1.10).

The training dataset then consists of pairs (\mathbf{x}_i,y_i) of allergen profiles \mathbf{x}_i and observed symptoms y_i.

Of course, many refinements are possible. For example, one could measure the amount of each allergen in each food item, incorporate the time elapsed before symptoms occurred, or record a more detailed measure of symptom severity.

An example solution for the second task is:

  • \mathcal{X} = \mathbb{R}^d, where \mathbf{x}_i contains the RGB values of each unobscured pixel in the ith image.

  • \mathcal{Y} = \mathbb{R}^p, where \mathbf{y}_i contains the RGB values of each obscured pixel in the ith image.

  • \mathcal{Z} = \mathbb{R}^p, so that the output f(\mathbf{x}) of a machine learning model represents a prediction for the values of the obscured pixels.

  • For example, L(\mathbf{y},\mathbf{z}) = \lVert \mathbf{y} - \mathbf{z} \rVert, as a simple measure of dissimilarity between the predicted and true hidden pixels.

The training dataset can be obtained by taking real images and artificially obscuring parts of them, producing inputs \mathbf{x}_i, while retaining the true hidden pixels \mathbf{y}_i as ground truth.

The choice of loss function here is in fact not ideal, because the generated pixels \mathbf{z} could look entirely realistic while still being very different from \mathbf{y} in a pixel-wise sense. A better approach would be to measure how well a classifier can distinguish real from fake hidden regions, but this idea has not yet been introduced; see Adversarial Training.

Important 2: Cross-entropy loss

Let Y_1,\dots,Y_n \sim \mathrm{Bern}(\rho) be independent, for an unknown success parameter \rho \in [0,1]. Estimating \rho can be cast as empirical risk minimisation with \mathcal{X} = \emptyset, f(\mathcal{X}) = \rho, and the cross-entropy loss L(y,\rho) = -\log p_\rho(y), where p_\rho is the probability mass function of \mathrm{Bern}(\rho). Compute the empirical risk minimiser \hat{\rho}.

Solution

The empirical risk is \mathcal{R}_n(f) = \frac{1}{n}\sum_{i=1}^n L(Y_i,\rho) = - \frac{1}{n}\sum_{i=1}^n \big[ Y_i \log \rho + (1-Y_i)\log(1-\rho) \big].

Differentiating with respect to \rho and setting the derivative equal to zero gives 0 = \partial_\rho \mathcal{R}_n(f) = - \frac{1}{n}\sum_{i=1}^n \left[ \frac{Y_i}{\rho} - \frac{1-Y_i}{1-\rho} \right].

Solving this equation yields \hat{\rho} = \frac{1}{n}\sum_{i=1}^n Y_i, the arithmetic mean of the data.

Important 3: The 0–1 loss

Let P be a probability distribution on \mathcal{X} \times \mathcal{Y} where \mathcal{Y} = \mathcal{Z} = \{0,1\}, and let L(y,z) = \begin{cases} 0, & y = z,\\ 1, & y \neq z, \end{cases} be the 0–1 loss. Let p(\cdot \mid \mathbf{x}) denote the probability mass function of Y \mid \mathbf{X}=\mathbf{x}.

Show that the Bayes predictor f_\star(\mathbf{x}) = \begin{cases} 1, & p(1\mid\mathbf{x}) \ge \displaystyle \frac{1}{2},\\ 0, & \text{otherwise}, \end{cases} is optimal, in the sense that no other function f : \mathcal{X} \rightarrow \mathcal{Z} achieves a lower risk \mathcal{R}(f).

Solution

Using the tower property of conditional expectation, the risk for a general function f : \mathcal{X} \rightarrow \mathcal{Z} is \begin{aligned} \mathcal{R}(f) &= \mathbb{E}_{(\mathbf{X},Y)\sim P}\!\left[ L\big(Y,f(\mathbf{X})\big) \right] \\ &= \mathbb{E}\!\left[ \mathbb{E}\!\left[ L\big(Y,f(\mathbf{X})\big)\mid \mathbf{X} \right] \right] \\ &= \mathbb{E}\!\left[ p(0\mid \mathbf{X})\, f(\mathbf{X}) + p(1\mid \mathbf{X})\,\big(1-f(\mathbf{X})\big) \right]. \end{aligned}

Since f(\mathbf{x}) can only take values in \{0,1\}, for each fixed \mathbf{X}=\mathbf{x} the inner expression is minimised by choosing f(\mathbf{x}) = f_\star(\mathbf{x}).

Because this choice can be made independently for each \mathbf{x}, it follows that f_\star minimises the risk \mathcal{R}(f).

Important 4: Neural networks and linear models

Show that the machine learning model \mathcal{F} = \{ f_{\boldsymbol{\theta}} \}_{\boldsymbol{\theta} \in \Theta}, where f_{\boldsymbol{\theta}} : \mathbb{R}^d \rightarrow \mathbb{R} is an L-layer fully connected neural network whose weights and bias parameters are collectively represented by \boldsymbol{\theta} \in \Theta, is identical to a linear model with features \phi_0(\mathbf{x}) = 1, \quad \phi_1(\mathbf{x}) = x_1, \dots, \phi_d(\mathbf{x}) = x_d when the identity activation function \sigma(z)=z is used1.

Solution

An L-layer fully connected neural network with scalar output can be written (see Example 1.15) as f_{\boldsymbol{\theta}}(\mathbf{x}) = \mathbf{w}^{(L)} \, \sigma\!\left( \mathbf{W}^{(L-1)} \sigma\!\left( \cdots \sigma\!\left( \mathbf{W}^{(1)}\mathbf{x} + \mathbf{b}^{(1)} \right) \cdots \right) + \mathbf{b}^{(L-1)} \right) + b^{(L)}, where \mathbf{w}^{(L)} is a row vector and b^{(L)} is a scalar.

If we substitute \sigma(\cdot) with the identity function, this becomes \begin{aligned} f_{\boldsymbol{\theta}}(\mathbf{x}) &= \mathbf{w}^{(L)} \Big( \mathbf{W}^{(L-1)} ( \cdots ( \mathbf{W}^{(1)}\mathbf{x} + \mathbf{b}^{(1)} ) \cdots ) + \mathbf{b}^{(L-1)} \Big) + b^{(L)} \\[4pt] &= \underbrace{ \big( \mathbf{w}^{(L)} \mathbf{W}^{(L-1)} \cdots \mathbf{W}^{(1)} \big) }_{=(\vartheta_1,\dots,\vartheta_d)} \mathbf{x} + \underbrace{ \big( \mathbf{w}^{(L)} \mathbf{W}^{(L-1)} \cdots \mathbf{W}^{(2)} \big) \mathbf{b}^{(1)} + \cdots + b^{(L)} }_{=\vartheta_0}. \end{aligned}

Writing the resulting coefficients as \boldsymbol{\vartheta}=(\vartheta_0,\vartheta_1,\dots,\vartheta_d), we obtain f_{\boldsymbol{\theta}}(\mathbf{x}) = \vartheta_0 \phi_0(\mathbf{x}) + \vartheta_1 \phi_1(\mathbf{x}) + \cdots + \vartheta_d \phi_d(\mathbf{x}), which is precisely a linear model (cf. Example 1.12).

Solution

The test risk begins to increase because the model is over-fitting to the training dataset. The deep neural network is very flexible and can start to exploit small artefacts in individual images that are unrelated to the underlying skin lesion itself, in order to memorise whether a particular training image was labelled as benign or malignant.

As training continues, the performance on the training set keeps improving, but the ability of the model to generalise to new, unseen images deteriorates.

Stopping gradient descent early reduces the opportunity for the neural network to pick up on these spurious patterns.

If early stopping is not desirable, then explicit regularisation strategies could be used instead, for example:

  • additive (weight) regularisation,
  • dropout,
  • or reducing the size and complexity of the neural network.

All of these approaches aim to limit how closely the model can fit the training data and thereby improve generalisation.

ImportantSums of kernels are kernels

Let k_1 : \mathcal{X} \times \mathcal{X} \rightarrow \mathbb{R} and k_2 : \mathcal{X} \times \mathcal{X} \rightarrow \mathbb{R} be kernels. Show that k(\mathbf{x},\mathbf{x}') = k_1(\mathbf{x},\mathbf{x}') + k_2(\mathbf{x},\mathbf{x}') is also a kernel. How is the feature space of k related to the feature space of k_1 and k_2?

Solution

Let’s check the axioms of a kernel hold for k.

For symmetry, k(\mathbf{x},\mathbf{x}') = k_1(\mathbf{x},\mathbf{x}') + k_2(\mathbf{x},\mathbf{x}') = k_1(\mathbf{x}',\mathbf{x}) + k_2(\mathbf{x}',\mathbf{x}) = k(\mathbf{x}',\mathbf{x}) where we have used the symmetry property of k_1 and k_2.

For positive semi-definiteness, \sum_{i=1}^n \sum_{j=1}^n w_i w_j k(\mathbf{x}_i,\mathbf{x}_j) = \underbrace{ \sum_{i=1}^n \sum_{j=1}^n w_i w_j k_1(\mathbf{x}_i,\mathbf{x}_j) }_{\geq 0} + \underbrace{ \sum_{i=1}^n \sum_{j=1}^n w_i w_j k_2(\mathbf{x}_i,\mathbf{x}_j) }_{\geq 0} \geq 0 for all w_1,\dots,w_n \in \mathbb{R}, all \mathbf{x}_1,\dots,\mathbf{x}_n \in \mathcal{X}, and all n \in \mathbb{N}, where we have used the positive semi-definiteness of k_1 and k_2.

Now, let k_1(\mathbf{x},\mathbf{x}') = \langle \boldsymbol{\phi}_1(\mathbf{x}) , \boldsymbol{\phi}_1(\mathbf{x}') \rangle and k_2(\mathbf{x},\mathbf{x}') = \langle \boldsymbol{\phi}_2(\mathbf{x}) , \boldsymbol{\phi}_2(\mathbf{x}') \rangle be explicit representations of k_1 and k_2 as feature space inner products. It follows that k(\mathbf{x},\mathbf{x}') = \langle \boldsymbol{\phi}_1(\mathbf{x}) , \boldsymbol{\phi}_1(\mathbf{x}') \rangle + \langle \boldsymbol{\phi}_2(\mathbf{x}) , \boldsymbol{\phi}_2(\mathbf{x}') \rangle = \left\langle \begin{pmatrix} \boldsymbol{\phi}_1(\mathbf{x}) \\ \boldsymbol{\phi}_2(\mathbf{x}) \end{pmatrix} , \begin{pmatrix} \boldsymbol{\phi}_1(\mathbf{x}') \\ \boldsymbol{\phi}_2(\mathbf{x}') \end{pmatrix} \right\rangle, so the feature space of k is the Cartesian product of the feature spaces of k_1 and k_2.

ImportantLogic via deep neural networks

Let \mathbf{x} \in \{0,1\}^d where d = 2^m for some m \in \mathbb{N}. Construct a neural network using the simple activation function \sigma(z) = \begin{cases} 1 & \text{if } z \geq 1 \\ 0 & \text{if } z < 1 \end{cases} to perform a parity check, i.e. to return 1 if the number of non-zero entries in \mathbf{x} is odd, and otherwise to return 0. State how many neurons and how many layers you used in your network as a function of d.

Hint: You may wish to make use of the XOR logic gate that we constructed in Activation Functions.

Solution

Let’s construct a neural network by induction, with base case m=1.

For the base case, we have a pair of inputs (x_1,x_2) \in \{0,1\}^2, and the XOR gate from Activation Functions returns 1 if and only if x_1 + x_2 is odd. That is, a single XOR gate performs a parity check when m = 1.

Now suppose we have a neural network that can perform a parity check when d = 2^{m-1}, and consider the case where d = 2^m. The state \mathbf{x} can then be decomposed into two parts, (\mathbf{x}_1,\mathbf{x}_2), each with length 2^{m-1}, and we can construct a neural network parity check f_i(\mathbf{x}_i) for each part i \in \{1,2\}. Then f(\mathbf{x}) = \mathrm{XOR}(f_1(\mathbf{x}_1) , f_2(\mathbf{x}_2)) is a neural network parity check for \mathbf{x}.

Let n_m be the number of neurons used to construct f; then n_m = 2 n_{m-1} + 3 since n_{m-1} neurons were used to construct each f_i and we used an additional 3 neurons to construct the final XOR gate. Solving the recursion, we need n_m = 3 \cdot 2^m - 3 neurons to perform the parity check.

Incrementing m adds an additional 2 layers to the neural network (recall Activation Functions) and thus the number of layers we need is 2m.

ImportantUniversal approximation with neural networks

Let f : [0,1] \rightarrow \mathbb{R} be piecewise linear with a finite number of pieces m (i.e. you can draw the graph of f by “joining the dots”). Show that f can be represented exactly using a neural network with the ReLU activation function \sigma(z) = \max\{0,z\}.

(A corollary of this result is that any continuous function f on a bounded interval can be arbitrarily well approximated, in the supremum norm, using a neural network with ReLU activation function; this is called a universal approximation result.)

Solution

First, note that all piecewise linear functions can be constructed as superpositions of triangular bump functions; f(x) = \sum_{i=0}^m t_{a_i,b_i,c_i}(x), \qquad t_{a,b,c}(x) = \begin{cases} 0 & x < a \\ \displaystyle \frac{x-a}{b-a} & a \leq x \leq b \\ \displaystyle \frac{c-x}{c-b} & b \leq x \leq c \\ 0 & x > c \end{cases}, for appropriate choices of the a_i, b_i, c_i \in \mathbb{R}.

It therefore suffices to show that we can construct triangular bump functions using neural networks with ReLU activation functions. This is indeed possible: t_{a,b,c}(x) = \left[ \sigma\left(\frac{x-a}{b-a}\right) - \sigma\left(\frac{x-b}{b-a}\right) \right] - \left[ \sigma\left(\frac{x-b}{c-b}\right) - \sigma\left(\frac{x-c}{c-b}\right) \right]

Concatenating these individual neural networks t_{a_i,b_i,c_i} into one wide neural network with at most 4(m+1) hidden units, we have expressed f as a neural network. Interestingly, this construction needed only one hidden layer in the neural network.

ImportantGradient descent

Explain why gradient descent, initialised at an arbitrary location \theta_0, and with fixed learning rate \epsilon, will not find the global minimum of F(\theta) = |\theta|.

Instead, suggest a suitable sequence (\epsilon_t)_{t = 1}^\infty and argue why, with your learning rate sequence, gradient descent on F will succeed (from any initial state \theta_0).

Solution

Let’s start with an obvious remark; the unique minimum occurs at \theta = 0, so we are concerned with whether or not the iterates (\theta_t)_{t=0}^\infty of gradient descent converge to 0.

A fixed learning rate \epsilon > 0 cannot work because then |\theta_{t+1} - \theta_t| = \epsilon |F'(\theta_t)| = \epsilon is bounded away from 0 for all t, so the sequence (\theta_t)_{t = 0}^\infty cannot be convergent (to any limit).

Consider instead \epsilon_t = t^{-p} for some power p > 0. We cannot take p = 0 because then the learning rate would be fixed. We also cannot take p > 1 because then the total distance we could hope to move is \sum_t |\theta_{t+1} - \theta_t| = \sum_t t^{-p} < \infty, and this may not be far enough to move from \theta_0 to 0 (e.g. for p=2 we cannot reach 0 if |\theta_0| > 2). This suggests we try taking p \in (0,1].

It remains only to argue why this works (we asked for an argument rather than a proof because to give a truly formal proof here would be unnecessarily technical).

First, since for this choice the total distance we move is infinite, we are guaranteed that (\theta_t)_{t=0}^\infty changes sign infinitely often. Second, if \theta_T and \theta_{T+1} have different signs, then |\theta_{T+1}| \leq |\theta_{T+1} - \theta_T| = \epsilon_T. Furthermore \theta_t \in [-\epsilon_T , \epsilon_T] for all t > T, since we cannot take two consecutive steps that each move us further from the origin.

Combining these two observations implies that \theta_t \rightarrow 0, as required. Indeed, given \gamma > 0 we can pick T_0 such that T_0^{-p} \leq \gamma, and we can find a T \geq T_0 such that \theta_{T+1} and \theta_T have different signs, implying that \theta_t \in [-\epsilon_T,\epsilon_T] \subseteq [-\gamma,\gamma] for all t > T, as required.

Important 6: Stochastic gradient is unbiased

Let \{i_j\}_{j=1}^m be a uniformly random subset of \{1,\dots,n\}, either with or without replacement3. Prove that \hat{S} = \frac{1}{m} \sum_{j=1}^m h(\mathbf{w}_{i_j}) is an unbiased estimator of S = \frac{1}{n} \sum_{i=1}^n h(\mathbf{w}_i).

Solution

From linearity of expectation, \mathbb{E}[\hat{S}] = \mathbb{E}\left[ \frac{1}{m} \sum_{j=1}^m h(\mathbf{w}_{i_j}) \right] = \frac{1}{m} \sum_{j=1}^m \mathbb{E}[ h(\mathbf{w}_{i_j}) ].

Now, since the i_j are uniformly distributed in \{1,\dots,n\}, it follows that each \mathbf{w}_{i_j} is uniformly distributed in \{\mathbf{w}_1,\dots,\mathbf{w}_n\}. Thus \mathbb{E}[ h(\mathbf{w}_{i_j}) ] = \frac{1}{n} \sum_{k = 1}^n h(\mathbf{w}_k).

Using this fact, we get \mathbb{E}[\hat{S}] = \frac{1}{m} \sum_{j=1}^m \frac{1}{n} \sum_{k = 1}^n h(\mathbf{w}_k) = \frac{1}{n} \sum_{k = 1}^n h(\mathbf{w}_k) = S, which shows that \hat{S} is an unbiased estimator for S, as required.

Important 7: Optimal learning rate for gradient descent

Obtain the optimal learning rate \epsilon = \frac{\|\boldsymbol{\theta}_0 - \boldsymbol{\theta}_\star\|}{\sqrt{T} B} as claimed in (Equation 3.7), by finding the value of \epsilon that minimises the bound from Theorem 3.1.

Important 8: Mean estimation as empirical risk minimisation

The aim of this exercise is to see how estimating the mean of a probability distribution can be cast within the empirical risk minimisation framework.

Let Y \sim P. Our aim is to estimate the mean of P from n independent observations of Y, which we denote \{y_i\}_{i=1}^n. To do so we introduce the squared error loss L(y,y') = (y-y')^2 and the “trivial” machine learning model \mathcal{F} = \mathbb{R}.

  1. Show that the (population) risk \mathcal{R}(\cdot) is minimised at f_\star = \mathbb{E}_{Y \sim P}[Y], the mean of P.
  2. Compute the empirical risk minimiser f_n \in \mathcal{F}.
  3. What is the generalisation error of f_n?
  4. Show that the expected generalisation error is \frac{1}{n} \mathbb{V}[Y] where \mathbb{V}[Y] is the variance of P.
  5. How many samples n are needed to guarantee an expected generalisation error smaller than \epsilon? (Recall this is the sample complexity of the empirical risk minimiser, telling us how much data we need to achieve a certain level of generalisation performance.)
Solution

The (population) risk is \mathcal{R}(f) = \mathbb{E}_{Y \sim P} [L(Y,f)] = \mathbb{E}_{Y \sim P} [ (Y-f)^2 ] = \mathbb{E}_{Y \sim P}[Y^2] - 2 f \mathbb{E}_{Y \sim P}[Y] + f^2, and this quadratic (in f) is minimised at f_\star = \mathbb{E}_{Y \sim P}[Y].

The empirical risk is \mathcal{R}_n(f) = \frac{1}{n} \sum_{i=1}^n L(y_i,f) = \frac{1}{n} \sum_{i=1}^n (y_i - f)^2 = \left( \frac{1}{n} \sum_{i=1}^n y_i^2 \right) - 2 f \left( \frac{1}{n} \sum_{i=1}^n y_i \right) + f^2 and this quadratic (in f) is minimised at f_n = \frac{1}{n} \sum_{i=1}^n y_i, the arithmetic mean of the dataset.

The generalisation error is \begin{aligned} \mathcal{R}(f_n) - \mathcal{R}(f_\star) & = \{ \mathbb{E}_{Y \sim P}[Y^2] - 2 f_n \mathbb{E}_{Y \sim P}[Y] + f_n^2 \} - \{ \mathbb{E}_{Y \sim P}[Y^2] - 2 f_\star \mathbb{E}_{Y \sim P}[Y] + f_\star^2 \} \\ & = \{ \mathbb{E}_{Y \sim P}[Y^2] - 2 f_n f_\star + f_n^2 \} - \{ \mathbb{E}_{Y \sim P}[Y^2] - f_\star^2 \} \\ & = f_\star^2 - 2 f_n f_\star + f_n^2 \\ & = (f_\star - f_n)^2. \end{aligned}

Let Y_i be a random variable representing the ith element of the dataset. The expected generalisation error is thus \begin{aligned} \mathbb{E}[ \mathcal{R}(f_n) - \mathcal{R}(f_\star) ] & = \mathbb{E}[ (f_\star - f_n)^2 ] \\ & = \mathbb{E}\left[ \left( \frac{1}{n} \sum_{i=1}^n Y_i - \mathbb{E}_{Y \sim P}[Y] \right)^2 \right] \\ & = \mathbb{V}\left[ \frac{1}{n} \sum_{i=1}^n Y_i - \mathbb{E}_{Y \sim P}[Y] \right] \\ & = \mathbb{V}\left[ \frac{1}{n} \sum_{i=1}^n Y_i \right] \\ & = \frac{1}{n} \mathbb{V}[Y] \end{aligned} where the final line follows from the properties \mathbb{V}[cY] = c^2 \mathbb{V}[Y] and \mathbb{V}[Y_i + Y_j] = \mathbb{V}[Y_i] + \mathbb{V}[Y_j] whenever i \neq j, since then Y_i and Y_j are independent.

To ensure an expected generalisation error less than \epsilon we therefore need n > \mathbb{V}[Y] / \epsilon number of independent samples in the dataset.

Important 9: Physics-informed machine learning

This exercise considers the problem of predicting spring displacement based on the force applied, following Example 2.4.

A “pure” machine learning approach would just use data to learn a predictive model, while a “pure” physics approach would use Hooke’s law of elasticity and attempt to learn the associated proportionality constant.

A physics-informed machine learning approach uses both the data and Hooke’s law, the latter entering as an additive regulariser on the empirical risk.

Indeed, for a twice differentiable f : [0,1] \rightarrow \mathbb{R}, consider the regulariser \begin{align*} R(f) = f(0)^2 + \int_0^1 f''(x)^2 \; \mathrm{d}x . \end{align*} Show that R(f) = 0 if and only if f represents an exact proportionality relationship (i.e. f(x) \propto x, which is the content of Hooke’s law).

Solution

If R(f) = 0 then f(0) = 0 and f''(x) = 0 for all x \in [0,1]. Integrating the latter gives that f'(x) = C for some constant C, and integrating again gives f(x) = C x + D for some additional constant D. Since f(0) = 0 we deduce that D = 0. Thus we have arrived at f(x) = C x, which is an exact proportionality relationship as claimed.

Important 10: Convex regularisation

Show that the regulariser R(\boldsymbol{\theta}) = \lVert \boldsymbol{\theta} \rVert_s is convex for each s \in \{1,2,\infty\}. Conversely, show that \lVert \boldsymbol{\theta} \rVert_0 (i.e. the number of non-zero entries in \boldsymbol{\theta}) is neither a norm nor convex.

Solution

To show convexity of R, we need to verify that R\big(\lambda \boldsymbol{\theta} + (1-\lambda)\boldsymbol{\vartheta}\big) \le \lambda R(\boldsymbol{\theta}) + (1-\lambda) R(\boldsymbol{\vartheta}) for all \boldsymbol{\theta},\boldsymbol{\vartheta}\in\mathbb{R}^p and all \lambda \in [0,1].

Now, for s\in\{1,2,\infty\} we know (or can check directly) that \lVert \cdot \rVert_s is a norm. Hence we may use the triangle inequality and homogeneity: \begin{aligned} \lVert \lambda \boldsymbol{\theta} + (1-\lambda)\boldsymbol{\vartheta} \rVert_s &\le \lVert \lambda \boldsymbol{\theta} \rVert_s + \lVert (1-\lambda)\boldsymbol{\vartheta} \rVert_s \\ &= \lambda \lVert \boldsymbol{\theta} \rVert_s + (1-\lambda)\lVert \boldsymbol{\vartheta} \rVert_s, \end{aligned} which is exactly the desired convexity inequality.

(The triangle inequality for general 1 \le s \le \infty is known as Minkowski’s inequality.)

To see that \lVert \cdot \rVert_0 is neither convex nor a norm, fix \lambda\in(0,1) and take \boldsymbol{\theta}\neq \mathbf{0}. Then \lVert \lambda \boldsymbol{\theta} + (1-\lambda)\mathbf{0} \rVert_0 = \lVert \lambda \boldsymbol{\theta} \rVert_0 = \lVert \boldsymbol{\theta} \rVert_0, whereas \lambda \lVert \boldsymbol{\theta} \rVert_0 + (1-\lambda)\lVert \mathbf{0} \rVert_0 = \lambda \lVert \boldsymbol{\theta} \rVert_0. Since \lVert \boldsymbol{\theta} \rVert_0 \nleq \lambda \lVert \boldsymbol{\theta} \rVert_0 for \lambda\in(0,1), the convexity inequality fails, so \lVert \cdot \rVert_0 is not convex.

Moreover, this same calculation shows it cannot be a norm: norms must satisfy homogeneity, \lVert \lambda \boldsymbol{\theta} \rVert = |\lambda| \lVert \boldsymbol{\theta} \rVert, but \lVert \lambda \boldsymbol{\theta} \rVert_0 = \lVert \boldsymbol{\theta} \rVert_0 for all \lambda\neq 0.

Important 12: Quadratic kernel

Express the quadratic kernel k(x,x') = (1 + x x')^2 as a feature space inner product k(x,x') = \langle \boldsymbol{\phi}(x), \boldsymbol{\phi}(x') \rangle.

Solution

There is no unique solution, but there is a most natural one. Expanding the square gives k(x,x') = 1 + 2xx' + x^2(x')^2.

We can realise this as an inner product by defining \boldsymbol{\phi}(x) = \begin{bmatrix} 1 \\ \sqrt{2}\,x \\ x^2 \end{bmatrix}, \qquad \boldsymbol{\phi}(x') = \begin{bmatrix} 1 \\ \sqrt{2}\,x' \\ (x')^2 \end{bmatrix}.

Then \langle \boldsymbol{\phi}(x), \boldsymbol{\phi}(x') \rangle = 1\cdot 1 + (\sqrt{2}x)(\sqrt{2}x') + x^2(x')^2 = 1 + 2xx' + x^2(x')^2 = k(x,x').

Other solutions correspond to re-ordering the features, or simple rescalings/splittings (e.g. replacing the feature x^2 with two copies of \frac{1}{\sqrt{2}}x^2).

Important 15: \epsilon-greedy bandits

Consider a 4-armed bandit, with arms labelled \{1,2,3,4\}. Your friend is playing the \epsilon-greedy strategy, meaning that at time t, with probability 1-\epsilon they play the bandit from which they have so far received the highest average reward, and with probability \epsilon they play a bandit chosen uniformly at random instead.

The bandit they choose to play is denoted B_t and the reward they receive is denoted R_t.

Your friend has no knowledge about which bandit is best at the outset and therefore assumes each bandit returns zero reward on average, until it has been tried.

Here is what happens next:

t B_t R_t
1 1 -1
2 2 1
3 2 -2
4 2 2
5 3 0

On some of these time steps the \epsilon case may have occurred, causing your friend to select a random bandit.

  • At which times t did this definitely happen?
  • At which times t did this definitely not happen?
Solution

The final part of this question is a trick: we can never rule out the possibility of the \epsilon case, because your friend could have selected the greedy bandit purely by chance.

To infer which time steps must have been \epsilon steps, suppose instead that we ourselves follow a purely greedy strategy and compare this behaviour with what actually happened.

After the first iteration, we have evidence that bandit 1 performs worse than expected, since B_1=1 and R_1=-1. We would therefore select one of the remaining bandits next, and we may take B_2=2.

The reward R_2=1 is encouraging, so we now believe that bandit 2 is best. A greedy strategy therefore plays bandit 2 again, giving B_3=2. The reward is now R_3=-2, so the empirical mean reward of bandit 2 becomes \frac{1}{2}(1-2)=-\frac{1}{2}.

At this point, a greedy strategy would switch to one of bandits 3 or 4. However, your friend instead played B_4=2. We therefore infer that time t=4 must have been an \epsilon step.

The reward is R_4=2, and the empirical mean reward of bandit 2 becomes \frac{1}{3}(1-2+2)=\frac{1}{3}, which is now the best option available.

A greedy strategy would therefore play bandit 2 again at the next step. Instead, your friend chose B_5=3, so time t=5 must also have been an \epsilon step.

In summary, the \epsilon case definitely occurred at iterations t=4 and t=5. At no iteration can we be certain that the \epsilon case did not occur.

Important 17: Score matching and maximum likelihood

Let P_{\boldsymbol{\theta}}=\mathcal{N}(\boldsymbol{\mu},\boldsymbol{\Sigma}) be a generative model for the dataset \{\mathbf{x}_i\}_{i=1}^n, where the parameters \boldsymbol{\theta} include the mean vector \boldsymbol{\mu} and the covariance matrix \boldsymbol{\Sigma}.

Recall that the maximum likelihood estimator for \boldsymbol{\mu} is the sample mean of the data and that the maximum likelihood estimator for \boldsymbol{\Sigma} is the sample covariance.

Show that, for this model, the score-matching estimator and the maximum likelihood estimator coincide.

Hint.
It may be easier to work with the precision matrix \boldsymbol{\Omega}=\boldsymbol{\Sigma}^{-1}. Useful identities include \partial_{\boldsymbol{\mu}} (\mathbf{x}-\boldsymbol{\mu})^\top \boldsymbol{\Omega}^2 (\mathbf{x}-\boldsymbol{\mu}) = -2\boldsymbol{\Omega}^2(\mathbf{x}-\boldsymbol{\mu}), \partial_{\boldsymbol{\Omega}}\operatorname{tr}(\boldsymbol{\Omega})=\mathbf{I}, \qquad \partial_{\boldsymbol{\Omega}} \mathbf{a}^\top\boldsymbol{\Omega}^2\mathbf{b} = 2\boldsymbol{\Omega}\mathbf{b}\mathbf{a}^\top .

Solution

Using the multivariate normal log-density (see Exercise 1.2), \log p_{\boldsymbol{\theta}}(\mathbf{x}) = -\tfrac12(\mathbf{x}-\boldsymbol{\mu})^\top \boldsymbol{\Sigma}^{-1} (\mathbf{x}-\boldsymbol{\mu}) + C_{\boldsymbol{\theta}}, where C_{\boldsymbol{\theta}} does not depend on \mathbf{x}, we obtain (\nabla_{\mathbf{x}}\log p_{\boldsymbol{\theta}})(\mathbf{x}) = -\boldsymbol{\Sigma}^{-1}(\mathbf{x}-\boldsymbol{\mu}), \qquad (\Delta_{\mathbf{x}}\log p_{\boldsymbol{\theta}})(\mathbf{x}) = -\operatorname{tr}(\boldsymbol{\Sigma}^{-1}).

The score-matching objective is therefore \arg\min_{\boldsymbol{\theta}} \; \frac{1}{n}\sum_{i=1}^n \lVert \boldsymbol{\Sigma}^{-1}(\mathbf{x}_i-\boldsymbol{\mu}) \rVert^2 - 2\,\operatorname{tr}(\boldsymbol{\Sigma}^{-1}).

Writing \boldsymbol{\Omega}=\boldsymbol{\Sigma}^{-1}, this can be expressed as \arg\min_{\boldsymbol{\mu},\boldsymbol{\Omega}} \; J(\boldsymbol{\mu},\boldsymbol{\Omega}) = \frac{1}{n}\sum_{i=1}^n \lVert \boldsymbol{\Omega}(\mathbf{x}_i-\boldsymbol{\mu}) \rVert^2 - 2\,\operatorname{tr}(\boldsymbol{\Omega}).

Differentiating and setting the gradients to zero gives \mathbf{0} = \nabla_{\boldsymbol{\mu}}J = -\frac{2}{n}\sum_{i=1}^n \boldsymbol{\Omega}^2(\mathbf{x}_i-\boldsymbol{\mu}), and \mathbf{0} = \nabla_{\boldsymbol{\Omega}}J = \frac{2}{n}\sum_{i=1}^n \boldsymbol{\Omega}(\mathbf{x}_i-\boldsymbol{\mu}) (\mathbf{x}_i-\boldsymbol{\mu})^\top - 2\mathbf{I}.

Rearranging yields \boldsymbol{\mu} = \frac{1}{n}\sum_{i=1}^n\mathbf{x}_i, \qquad \boldsymbol{\Sigma} = \boldsymbol{\Omega}^{-1} = \frac{1}{n}\sum_{i=1}^n (\mathbf{x}_i-\boldsymbol{\mu}) (\mathbf{x}_i-\boldsymbol{\mu})^\top .

These are exactly the sample mean and sample covariance. Hence, for a multivariate Gaussian model, the score-matching estimator coincides with the maximum likelihood estimator.

Important 18: Ethical considerations

After graduating from Newcastle University you join a tech start-up that wants you to develop a machine learning model capable of automatically ranking candidates for a given job advert. Only the top-k ranked candidates will be interviewed. The ranking should be determined solely from the content of the job advert and the content of candidates’ LinkedIn profiles.

Describe some of the ethical issues that might arise in this context.

Solution

Some relevant considerations include:

  • Training data and consent.
    Historical recruitment data (for example, previous short-listing decisions) would be required for training and should only be used with appropriate consent.

  • Fairness.
    The training data may not be representative of the population of future applicants. If this is the case, the resulting model may perpetuate or amplify existing biases.

  • Responsibility.
    What safeguards will prevent the system from recommending inappropriate rankings? Should a human decision-maker always review the output?

  • Transparency.
    Will candidates be informed about how interview decisions were made, and can meaningful explanations be provided?

  • Inequality.
    Is it fair to base decisions solely on LinkedIn profiles? Could this disadvantage particular groups of candidates?

  • Veracity.
    Information on LinkedIn may be incomplete, outdated or inaccurate.

These points are not exhaustive, but they highlight some of the key issues that arise when deploying machine learning systems in hiring.

Important 19: PyTorch tensors: vectors and matrices I

In machine learning, data are typically represented using vectors and matrices.

Consider the vector

\bm{x} = \begin{pmatrix} 1 \\ 2 \\ 3 \end{pmatrix}

and the matrices

A = \begin{pmatrix} 1 & 2 & 0 \\ 0 & 1 & 3 \\ 2 & 0 & 1 \end{pmatrix}, \qquad B = \begin{pmatrix} 1 & 0 & 2 \\ 3 & 1 & 0 \\ 0 & 2 & 1 \end{pmatrix}.

Questions

  1. Using PyTorch, create the vector x and the matrices A and B. Use dtype torch.float32.

  2. Using PyTorch operations (no loops), compute:

    1. the sum of each row of A

    2. the sum of each column of A

    3. the matrix product AB

    4. the matrix-vector product Ax

    5. the scalar value x^\top A x

Solution

One possible implementation in PyTorch is given below:

import torch

# Part 1: create vector and matrices

x = torch.tensor(
    [1, 2, 3],
    dtype=torch.float32
)

A = torch.tensor(
    [
        [1, 2, 0],
        [0, 1, 3],
        [2, 0, 1],
    ],
    dtype=torch.float32
)

B = torch.tensor(
    [
        [1, 0, 2],
        [3, 1, 0],
        [0, 2, 1],
    ],
    dtype=torch.float32
)

print("x shape:", x.shape)
print("A shape:", A.shape)
print("B shape:", B.shape)

# Part 2(a): row sums
row_sums = A.sum(dim=1)
print("\nRow sums of A:")
print(row_sums)

# Part 2(b): column sums
col_sums = A.sum(dim=0)
print("\nColumn sums of A:")
print(col_sums)

# Part 2(c): matrix product AB
AB = A @ B
print("\nAB:")
print(AB)

# Part 2(d): matrix-vector product Ax
Ax = A @ x
print("\nAx:")
print(Ax)

# Part 2(e): scalar x^T A x
xTAx = x @ A @ x
print("\nx^T A x:")
print(xTAx)

Important 20: PyTorch tensors: vectors and matrices II

In PyTorch, it is common to work with a batch of matrices, where several matrices are stored together in a single tensor.

For example, the following code defines a batch of three 2 \times 2 matrices and a vector of length 2, and computes a matrix–vector product.

import torch

A = torch.tensor(
    [
        [[1, 2],
         [3, 4]],

        [[0, 1],
         [1, 0]],

        [[2, 0],
         [0, 2]],
    ],
    dtype=torch.float32
)

x = torch.tensor(
    [1, 2],
    dtype=torch.float32
)

y = A @ x

Questions

  1. State the shape of A, x, and y.

  2. How many matrix–vector multiplications are being performed?

  3. Compute the value of y by hand.

  4. Explain in words why PyTorch is able to perform this computation, even though A is not a single matrix.

  5. Suppose that, without changing A, instead we define x as in the following code. State the shape of A @ x.

x = torch.tensor(
    [
        [1, 2],
        [3, 4],
        [5, 6],
    ],
    dtype=torch.float32
)
Solution

We answer each part in turn.

  1. Shapes. A \text{ shape} = (3, 2, 2), \qquad x \text{ shape} = (2), \qquad y \text{ shape} = (3, 2)
  2. Number of multiplications. Three matrix–vector multiplications are performed — one for each matrix in the batch.
  3. Compute by hand. First matrix: \begin{pmatrix} 1 & 2 \\ 3 & 4 \end{pmatrix} \begin{pmatrix} 1 \\ 2 \end{pmatrix} = \begin{pmatrix} 5 \\ 11 \end{pmatrix} Second matrix: \begin{pmatrix} 0 & 1 \\ 1 & 0 \end{pmatrix} \begin{pmatrix} 1 \\ 2 \end{pmatrix} = \begin{pmatrix} 2 \\ 1 \end{pmatrix} Third matrix: \begin{pmatrix} 2 & 0 \\ 0 & 2 \end{pmatrix} \begin{pmatrix} 1 \\ 2 \end{pmatrix} = \begin{pmatrix} 2 \\ 4 \end{pmatrix} So y = \begin{pmatrix} 5 & 11 \\ 2 & 1 \\ 2 & 4 \end{pmatrix}
  4. Explanation. PyTorch treats the first dimension as a batch dimension. It performs the matrix multiplication separately for each matrix, and stacks the results into a single tensor.
  5. New shape. Now A \text{ shape} = (3,2,2), \qquad x \text{ shape} = (3,2) so each batch element multiplies its corresponding vector. The result has shape (3,2).
Important 21: PyTorch tensors: vectors and matrices III

In deep learning, tensors often contain batches of matrices, and it is important to understand the shapes of the outputs of matrix multiplication.

Consider the following PyTorch code.

import torch

A = torch.zeros((5, 2, 3))
B = torch.zeros((3, 4))
C = torch.zeros((5, 3, 4))
D = torch.zeros((2, 3))

For each of the following operations, state the shape of the result, or state that the operation is not valid.

Do not execute the code.

  1. A @ B
  2. A @ C
  3. D @ B
  4. B @ C
  5. Explain briefly, in words, the general rule that PyTorch uses when performing matrix multiplication with batched tensors.
Solution

We answer each part in turn.

  1. Operation is valid with shape: (5,2,4)
  2. Operation is valid with shape: (5,2,4)
  3. Operation is valid with shape: (2,4)
  4. Operation is not valid. The inner matrix dimensions do not match.
  5. General rule:
    • The last two dimensions are matrix dimensions.
    • Any earlier dimensions are batch dimensions.
    • Matrix multiplication is performed separately for each batch.
    • If a tensor A has shape (\dots, m, n) and another B has shape (\dots, n, p), then the matrix multiplication A @ B is valid and the result has shape (\dots, m, p).
